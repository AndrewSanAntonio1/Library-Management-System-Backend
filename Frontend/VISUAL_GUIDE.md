```
        ╱╲              ← Cockpit (Glowing blue sphere)
       ╱  ╲
      ╱    ╲
     ╱      ╲           ← Main body (Blue cone)
    ◄────────►          ← Wings (Flat panels)
     ╲      ╱
      ╲    ╱
       ╲  ╱
        ╲╱
        ◉◉              ← Engine (Glowing effect)
```

### Animation Pattern
```
Y Position (Floating):
    ^
  2 │     ╱‾‾‾‾╲
    │   ╱        ╲
  0 │ ╱            ╲─
    │               
 -2 └────────────────────→ Time
    Sine wave motion

    ↻ Slow continuous rotation
    0° → 360° over 20 seconds
```
